# Lesson Learned — 원/달러 연저점 구간과 해외자산 누적매수

Date: 2026-09-07
Status: REGISTERED / RULE REFINED

## 1. Observation

원/달러 환율은 2026-09-07 서울 외환시장 종가 1,340.5원으로, 2024-03-19 이후 약 2년 6개월 만의 낮은 주간거래 종가를 기록했다. 장중에는 1,334.7원까지 하락했다. 2026-07-01 고점 1,559.2원 대비 약 14% 낮아진 수준이다.

이번 점검에서 확인한 핵심은 환율 하락 자체를 단기 방향성 베팅으로 해석하기보다, 해외자산을 원화 기준으로 유리하게 취득할 수 있는 조건으로 활용해야 한다는 점이다.

## 2. Core Lesson

기존 문구의 방향은 유지하되 다음과 같이 정의를 정교화한다.

> 환율 하락은 해외자산의 매도 신호가 아니라 신규 해외자산의 원화 취득가격을 개선하는 실행 우호 조건이다. 단, 환율 자체를 단독 매수 신호로 사용하지 않고 자산가격, 추세/시장위험, 포트폴리오 목표비중과 결합하여 분할매수 강도를 결정한다.

중요한 구분:

- 기존 달러자산 보유자에게 원화 강세는 원화 환산 평가액을 낮추는 요인이다.
- 신규 매수자에게 원화 강세는 같은 달러 자산을 더 적은 원화로 취득할 수 있는 요인이다.
- 따라서 동일한 환율 변화가 '기존 보유자'와 '신규 취득자'에게 서로 다른 의사결정 의미를 가진다.
- 환율 하락만으로 미래 해외자산 수익률이 좋아진다고 가정하지 않는다.

## 3. FX-ACCUMULATION RULE v0.2

환율은 독립적인 매매 트리거가 아니라 `Execution Modifier`로 취급한다.

### 3.1 판단 순서

1. **Portfolio Gap** — 해당 해외자산이 목표비중보다 얼마나 부족한가
2. **Asset Opportunity** — 자산가격이 합리적인 취득구간인가
3. **Trend / Risk** — 추세 훼손, 변동성, 거시위험이 매수를 제한하는가
4. **FX Benefit** — 환율이 신규 취득가격에 얼마나 유리한가
5. **Cash Budget** — 사전 정의한 현금 및 위험한도를 초과하지 않는가

즉,

`Buy Intensity = Portfolio Gap × Asset Opportunity × Risk Gate × FX Benefit`

로 개념화한다. 실제 수식과 가중치는 과거 구간 replay로 검증하기 전까지 고정하지 않는다.

### 3.2 FX 역할

| 조건 | 해석 | 기본 역할 |
|---|---|---|
| 원화 강세 + 해외자산 가격 안정/조정 | 신규 취득가격 개선 | 매수 강도 상향 가능 |
| 원화 강세 + 해외자산 급등 | 환율 이점이 자산가격 상승에 상쇄될 수 있음 | 기본 적립 유지, 과대매수 금지 |
| 원화 강세 + 해외자산 추세 훼손/고위험 | 환율 이점보다 자산위험이 큼 | 매수 강도 축소 |
| 원화 약세 + 해외자산 급락 | 자산가격은 싸지만 환전비용이 불리함 | 분할매수 유지, FX만으로 중단하지 않음 |
| 원화 약세 + 해외자산 고평가 | 이중 불리 | 신규 매수 규모 축소 |

## 4. Existing FX Trigger Bands

아래 환율대는 예측값이 아니라 운영용 Trigger다.

| USD/KRW | 기본 행동 |
|---:|---|
| 1,340~1,350 | 1차 해외자산 매수 구간 |
| 1,320~1,330 | 2차 매수 확대 검토 |
| 1,300~1,320 | 적극적 해외자산 매수 검토 |
| 1,280~1,300 | 극단적 원화 강세; 시장위험 확인 후 추가 확대 검토 |
| 1,380~1,420 | 신규 달러 매수 규모 축소 |
| 1,450 이상 | 신규 달러 매수 엄격 제한; 기존 해외자산 유지 중심 |

단, v0.2에서는 위 절대 환율대를 최종 판단 기준으로 사용하지 않는다. 장기적으로는 최근 3년/5년 분포상 위치(백분위), 환율 하락 속도, 자산가격과의 동시 움직임을 함께 검토한다.

## 5. Current Market Example — 2026-09-07

현재 원/달러는 1,340.5원으로 4거래일 연속 하락했고, 최근 고점 1,559.2원 대비 약 14% 낮아졌다. 시장에서는 달러 공급 우위가 이어질 경우 1,320원 부근까지 추가 하락 가능성을 거론하고 있다.

그러나 같은 시점 미국 주식은 9월 4일 S&P 500 7,718.60으로 전고점 인근이고, VIX는 14.53 수준이었다. 따라서 현재 환경은 '환율이 싸졌으니 미국주식을 강하게 매수'하는 상황이라기보다, 해외자산 목표비중이 부족한 경우 **기본 적립 + 환율 우호 조건을 활용한 제한적 추가매수**가 더 일관된 해석이다.

## 6. Important Guardrails

다음 경우 환율의 가점을 낮추거나 제거한다.

- 환율 하락이 일시적 이벤트인지 구조적 수급 변화인지 불명확한 경우
- 해외자산 밸류에이션 또는 추세 위험이 환율 이점을 초과하는 경우
- 환율이 특정 저점에 도달할 것이라는 예측에 매수가 종속되는 경우
- 환율 하락 때문에 기존 해외자산을 매도하는 경우
- 환헤지 상품처럼 환율 효과가 구조적으로 제한된 상품에 동일 규칙을 적용하는 경우
- 목표비중, 현금관리, 최대 손실한도를 초과하는 경우

## 7. Falsification Hypotheses

검증에서 다음 가설을 반증 대상으로 둔다.

- H1: 낮은 USD/KRW 구간에서의 추가매수가 단순 적립식보다 원화 기준 장기 취득단가를 개선한다.
- H2: FX 단독 Trigger보다 `FX × Asset Price × Portfolio Gap` 결합 Trigger가 최대낙폭 증가 없이 매수효율을 개선한다.
- H3: 절대 환율대보다 rolling percentile 기반 FX score가 다른 시기에도 더 안정적인 Trigger Frequency를 만든다.
- H4: 환율 하락기에 기존 해외자산을 매도하는 전략은 장기 자산배분 관점에서 매수/보유 전략보다 우월하지 않다.

평가 항목:

- 미탐(False Negative)
- 조기 탐지 시간(Lead Time)
- 경보 발생 횟수(Trigger Frequency)
- 최종 취득단가
- CAGR / 누적수익률
- 최대낙폭(Max Drawdown)
- 현금 소진 속도

판정 기준은 백테스트 성과 하나가 아니라 **수익성 + 위험 + 경보 안정성 + 현금관리**를 함께 본다.
