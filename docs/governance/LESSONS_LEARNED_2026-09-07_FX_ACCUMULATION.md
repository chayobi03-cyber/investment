# Lesson Learned — 원/달러 연저점 구간과 해외자산 누적매수

Date: 2026-09-07
Status: REGISTERED

## 1. Observation

원/달러 환율이 1,340원대까지 내려오며 최근 저점 구간에 진입했다.

이번 점검에서 확인한 핵심은 환율 하락 자체를 단기 방향성 베팅으로 해석하기보다, 해외자산을 원화 기준으로 유리하게 확보할 수 있는 조건으로 활용해야 한다는 점이다.

## 2. Lesson Learned

환율이 낮다는 이유만으로 달러 또는 미국자산을 일시에 매수하지 않는다.

환율은 다음 세 가지 중 하나로 사용한다.

1. 해외자산 신규매수의 허용 조건
2. 해외자산 비중 확대의 보조 신호
3. 미국 증시 조정과 결합될 때 매수 강도를 높이는 신호

따라서 FX 단독 예측보다 `환율 × 자산가격 × 시장위험`의 결합 판단이 우선한다.

## 3. FX-ACCUMULATION RULE v0.1

| USD/KRW | 기본 행동 |
|---:|---|
| 1,340~1,350 | 1차 해외자산 매수 구간 |
| 1,320~1,330 | 2차 매수 확대 |
| 1,300~1,320 | 적극적 해외자산 매수 검토 |
| 1,280~1,300 | 극단적 원화 강세 구간; 시장위험 확인 후 추가 확대 검토 |
| 1,380~1,420 | 신규 달러 매수 규모 축소 |
| 1,450 이상 | 신규 달러 매수 엄격 제한; 기존 해외자산 유지 중심 |

위 구간은 예측값이 아니라 운영용 Trigger이며, 실제 주문은 해외자산 가격과 시장위험 조건을 함께 확인한다.

## 4. Portfolio Application

현재 포트폴리오에서는 이미 삼성전자 코어 비중이 높으므로, 원화 강세를 활용한 추가 노출은 국내 반도체보다 해외자산의 분산효과를 우선 검토한다.

장기 해외 코어자산은 환율 자체를 맞히기 위한 환헤지보다 `원화자산 + 달러자산`의 위험요인 분산 기능을 유지하는 방향을 기본값으로 둔다.

## 5. Falsification / Guardrails

다음 경우 룰의 매수 강도를 낮추거나 중단한다.

- 원화 강세가 구조적 수급이 아니라 일시적 이벤트로 판명되는 경우
- 미국자산 밸류에이션/시장위험이 악화되어 환율 하락의 이점보다 자산가격 위험이 커지는 경우
- 환율이 낮다는 사실만으로 최저점을 확정하려는 경우
- 실제 집행이 사전 정의한 비중 또는 현금관리 범위를 초과하는 경우
