# Lessons Learned — Anthropic IPO + FX + Indirect Exposure

**Date:** 2026-09-06

## Lesson Learned

The Anthropic IPO thesis cannot be evaluated from the IPO headline valuation alone. The market is underwriting forward revenue, while compute commitments create a potentially large cost burden. Public-filing unit economics are therefore the primary validation gate.

A second lesson is that “indirect Anthropic exposure” is not one homogeneous trade. Strategic investors (for example, cloud platforms), compute suppliers, semiconductor suppliers and ecosystem ETFs transmit the event through different causal paths and must be separated in the benchmark.

A third lesson is that KRW investor returns require an explicit FX layer. USD/KRW directly changes the KRW return of an unhedged U.S.-listed proxy, while JPY/KRW should be treated as an Asian liquidity/risk-regime overlay rather than an Anthropic attribution factor.
