# Lesson Learned — 2026-09-02 Stress Convergence

## Lesson

Macro-risk research should not stop at a narrative chain. A usable investment early-warning system requires explicit Threshold, Trigger, Falsifier, and Action Level definitions.

## Rule update

Future investment-risk hypotheses should be converted through this sequence:

Claim → Indicator → Threshold → Trigger → Independent Confirmation → Falsifier → Action Level → Backtest → Calibration

## Important control

Avoid double counting correlated indicators from the same causal chain. High-level escalation requires independent economic axes and persistence.

## Next action

Backtest the provisional Stress Convergence thresholds against crisis and false-positive periods before treating the action levels as validated.
