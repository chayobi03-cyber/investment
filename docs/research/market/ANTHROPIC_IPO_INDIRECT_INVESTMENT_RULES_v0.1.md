# Anthropic IPO Indirect-Investment / FX Rules v0.1

**Effective:** 2026-09-06

## Rule R1 — Direct vs proxy separation

Anthropic equity exposure and Anthropic-ecosystem exposure MUST be represented as separate instruments. Amazon/Alphabet/semiconductor equities and ANTW are proxies, not substitutes for Anthropic shares.

## Rule R2 — Run-rate is not GAAP

Headline annualized revenue/run-rate MUST NOT be used as if it were audited GAAP revenue. Before valuation scoring, reconcile revenue definition, partner accounting, gross margin and compute costs from the public filing.

## Rule R3 — Forward valuation must be explicit

When market valuation depends on 2028E or other forward revenue, record the forecast horizon and calculate valuation / forward revenue explicitly. Do not mix current run-rate multiples with forward-revenue multiples.

## Rule R4 — FX is a return multiplier

For unhedged USD assets, KRW investor return MUST include the USD/KRW translation effect. Report asset return and FX return separately before combining them.

## Rule R5 — JPY/KRW is an overlay, not an attribution factor

JPY/KRW may be used as an Asian liquidity/risk-regime overlay but MUST NOT be treated as direct evidence that Anthropic caused a market move.

## Rule R6 — Indirect-beneficiary attribution requires earnings linkage

A positive Anthropic event is not sufficient to classify AMZN, GOOGL, NVDA, AVGO, MU, SK hynix or Samsung as beneficiaries. Each must have an explicit transmission mechanism and measurable earnings/valuation sensitivity.

## Rule R7 — ETF launch-stage status

ANTW MUST be classified as launch-stage/registered until live operations and holdings are confirmed. Its 0.59% management fee and stated ecosystem mandate should be recorded, but no live performance inference should be made before inception data exist.

## Rule R8 — Event-study benchmark freeze

After the Anthropic public prospectus is released, event-study comparisons should use a fixed benchmark set: Nasdaq/QQQ, S&P 500, DXY, USD/KRW, JPY/KRW, U.S. 10Y/30Y yields, AMZN, GOOGL, NVDA, AVGO, MU, SK hynix and Samsung Electronics.

## Rule R9 — Separate narrative/evidence/crisis judgments

Consistent with NARRATIVE_VALIDATION_WORKFLOW_v0.1, Anthropic IPO narrative strength, evidence strength and crisis confirmation MUST remain separate judgments.
