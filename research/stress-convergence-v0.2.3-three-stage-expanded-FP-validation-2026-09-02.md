# Stress Convergence v0.2.3 — 3단계 경보 구조 + 확대 오탐 구간 검증

Date: 2026-09-02
Status: PROTOCOL + EVENT-WINDOW PRELIMINARY VALIDATION

## 0. 목적

이번 실험은 경보를 한 번에 "위기"로 판단하지 않고 다음 3단계로 나눈다.

1. **조기경보 (Early Warning)** — 위험한 방향으로 움직이기 시작했는지 본다.
2. **경계 강화 (Tightening State)** — 금리 상승 압력이 실제로 강해지고 있는지 본다.
3. **위기 확인 (Crisis Confirmation)** — 신용·유동성·고용·주가 하락 등 실제 위기 징후가 함께 나타나는지 확인한다.

같은 확대 오탐 테스트 구간에 이 구조를 적용하여 다음 4가지를 비교한다.

- 오탐: 위기가 아닌데 경보가 발생한 횟수
- 미탐: 위기인데 놓친 횟수
- 조기 탐지 시간: 실제 위기 전에 얼마나 빨리 잡았는지
- 경보 발생 횟수: 테스트 기간에 경보가 몇 번 발생했는지

## 1. 현재까지 동결된 기본 규칙

- R = 10Y 금리 >= 최근 12개월 최저치 +40bp
- I = 미국 CPI 전년비 증가율 >= 3개월 전보다 +0.4%p
- R+I 지속 = 주간 기준 2회 연속
- L = 실업률 >= 최근 12개월 최저치 +0.3%p
- C = HY OAS >= 최근 6개월 최저치 +75bp
- V = VIX >=25가 5거래일 이상 지속
- E = S&P 500이 최근 60거래일 고점보다 10% 이상 하락

## 2. 3단계 구조

### 2.1 조기경보

`R + I 지속 2주`

역할: 금리와 물가가 동시에 압박을 높이는 초기 국면을 놓치지 않는다.

### 2.2 경계 강화

`조기경보 + D2 상태`

D2 = `2Y 금리 >= 최근 12개월 최저치 + X bp`

중요한 변경점: D2는 더 이상 "위기"를 판정하는 필수 조건이 아니다. 금리 재가격 강도를 설명하는 별도 상태값으로 사용한다.

이번 실험의 해석용 구간:

- < +40bp: 일반 수준
- +40 ~ +60bp: 경계 강화
- >= +60bp: 강한 긴축 재가격

위 구간은 새 최적값을 고르는 용도가 아니라 상태를 나누기 위한 해석축이다.

### 2.3 위기 확인

기존의 독립적인 위기 경로를 사용한다.

- Credit/Liquidity: `C + V + (L OR E)`
- Growth/Exogenous: `L + (E OR V) + (C OR R)`

즉, D2만으로 위기를 확정하지 않는다.

## 3. 동일 확대 테스트 세트

기존 7개 구간에 다음 비위기 긴축 구간을 추가한다.

| 구간 | 분류 |
|---|---|
| 1994 긴축 | 확대 오탐 테스트 |
| 2004–05 긴축 | 확대 오탐 테스트 |
| 2013 taper tantrum | 기존 오탐 |
| 2016 China/energy stress | 기존 오탐 |
| 2017 reflation / Fed tightening | 확대 오탐 테스트 |
| Q4 2018 tightening selloff | 기존 테스트 |
| 2021 reflation / taper / pre-2022 tightening | 확대 오탐 테스트 |

위기 구간은 기존과 동일하게 2000 / 2008 / 2020 / 2022를 사용한다.

## 4. 현재까지 확인된 기준 결과

기존 7개 구간에서 확인된 결과는 다음과 같다.

| 규칙 | 위기 놓침 | 비위기 오탐 | 핵심 특징 |
|---|---:|---:|---|
| B: 조기경보만 | 0/4 | 2/3 | 가장 빨리 잡지만 일반 긴축도 자주 경보 |
| C: 조기경보 지속기간 제한 | 1/4 | 2/3 | 경보가 오래 유지되는 문제만 줄이고 오탐 문제는 해결하지 못함 |
| D: 조기경보 + D2 필수 | 0/4 | 0/3 | 기존 7개에서는 가장 깔끔하지만 2022 조기 탐지가 약 3일로 늦어짐 |

D2 +60bp는 기존 7개에서 좋은 결과를 냈지만, 확대 테스트에서는 1994·2004–05·2017·2021 같은 일반 긴축에서도 크게 움직일 수 있다는 구조적 한계가 확인되었다.

따라서 **D2를 위기 확정용 필수 조건으로 계속 사용하지 않는다.**

## 5. 3단계 구조의 현재 판정

### 조기경보

목표: "위험한 방향으로 움직이기 시작했다"를 빨리 알린다.

평가 기준: 미탐을 최대한 줄이고 조기 탐지 시간을 확보한다.

### 경계 강화

목표: "금리 상승 압력이 실제로 강해지고 있다"를 보여준다.

평가 기준: 조기경보보다 확신을 높이되, 이것만으로 위기라고 부르지 않는다.

### 위기 확인

목표: 실제 시장 충격으로 이어지고 있는지를 판단한다.

평가 기준: 신용·유동성·고용·주가 하락 같은 독립적인 위험 신호가 같이 발생하는지 본다.

## 6. 핵심 설계 변경

기존 방식:

`R+I 지속 + D2 -> 위기 경보`

새 방식:

`R+I 지속 -> 조기경보`

`조기경보 + D2 강도 -> 경계 강화`

`독립적인 위기 신호 -> 위기 확인`

즉, 한 개의 임계값으로 "빨리 경보"와 "정확하게 위기 확인"을 동시에 해결하려 하지 않는다.

## 7. 확대 테스트에서 반드시 실제로 계산할 숫자

다음 실행에서는 각 구간에 대해 날짜 단위로 아래 값을 계산한다.

| 항목 | 의미 |
|---|---|
| 조기경보 발생일 | 처음 위험 신호가 잡힌 날짜 |
| 경계 강화 발생일 | D2가 강화 구간에 진입한 날짜 |
| 위기 확인일 | 독립적인 위기 경로가 충족된 날짜 |
| 실제 위기 기준일 | S&P 고점/사건 기준일 |
| 조기 탐지 시간 | 기준일 - 각 경보 발생일 |
| 오탐 | 비위기 구간에서 위기 확인까지 올라간 경우 |
| 미탐 | 위기 구간에서 위기 확인에 실패한 경우 |
| 경보 발생 횟수 | 전체 테스트 기간 중 실제 발동 횟수 |

## 8. 현재 검증 한계

현재 Git 저장소에는 이번 확대 세트를 **매일 단위로 재실행할 수 있는 원시 데이터 패널과 실행 코드가 함께 들어 있지 않다.**

따라서 이 문서에서 새로 만들어낸 수치를 "실측값"이라고 표시하지 않는다.

현재까지의 숫자는 기존 이벤트-window 재실행 결과에서 확인된 값이며, 확대 7+4 구간의 완전한 날짜별 FP/FN/Lead Time/Trigger Frequency는 **daily-panel 실행이 추가되어야 확정할 수 있다.**

## 9. 중간 결론

현재까지의 증거로는 다음을 확정한다.

1. 조기경보 단계는 민감도를 유지하는 역할을 한다.
2. D2는 조기경보를 바로 위기 판정으로 바꾸는 조건이 아니라 **긴축 강도**를 설명하는 상태 정보로 쓰는 편이 타당하다.
3. 실제 위기 판정은 독립적인 신용·유동성·고용·주가 경로가 맡아야 한다.
4. 따라서 최종 구조는 `조기경보 → 경계 강화 → 위기 확인` 3단계로 분리한다.

## 10. 다음 실행

다음 실행의 목표는 설계가 아니라 **실측**이다.

확대 11개 구간 전체를 같은 날짜별 데이터로 다시 돌려서:

- 오탐 횟수
- 미탐 횟수
- 각 단계의 조기 탐지 시간
- 경보 발생 횟수

를 B/C/D와 직접 비교한다.

그 결과가 나오기 전에는 v0.2.3을 최종 규칙으로 승격하지 않는다.

## 11. Lesson Learned

- 하나의 조건에 너무 많은 역할을 맡기면 민감도와 정확도가 충돌한다.
- 금리 2년물 상승은 유용한 정보지만 그 자체가 "위기"는 아니다.
- 앞으로는 "시작 감지", "긴축 강도", "실제 위기 확인"을 서로 다른 단계로 관리한다.
